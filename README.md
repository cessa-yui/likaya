# LÍKAYA

A responsive clothing-brand showcase. Original campaign image, mobile navigation, accessible anchor links, and a coming-soon collection section.

## Deployment

Import this repository into Vercel. Framework: Other. No build or install command. Output directory: `.`. The included `vercel.json` sets these options. Connect the `main` branch for production updates.

## Editing

- `index.html`: website copy and section structure
- `styles.css`: responsive layout and visual styling
- `script.js`: mobile navigation
- `campaign.webp`: original AI-generated conceptual campaign photography

Copy, campaign styling, and imagery are proposed creative direction, not verified product information. The site has no checkout, product inventory, prices, newsletter collection, shipping promises, or invented contact details. Replace the conceptual campaign with real brand/product imagery when available.
